ITM_WPN_GNR_0013 — 눈싸움시간! 정식 3D 제작 브리프

중요: Tripo P1 multiview_to_model API 자체에는 텍스트 prompt 필드가 없으므로, 이 문서는 최종 4면도 제작과 Blender 후처리에 적용한 고정 디자인 브리프다. Tripo에는 Prepared/TripoInput의 front, left, back, right PNG 네 장을 순서대로 직접 전달한다.

원본 카드 디자인을 충실하게 재현한 스타일라이즈드 거너용 유탄발사기를 제작한다. 흰색, 실버, 건메탈, 빙청색을 주색으로 사용하고, 적색은 작은 기계 포인트와 표시등에만 제한한다. 전체 인상은 차갑고 맑은 얼음·냉각 장비여야 하며, 한눈에 양손으로 드는 유탄발사기임을 알 수 있어야 한다.

중앙의 냉각 챔버는 투명한 실제 유리/얼음 껍질이어야 하며 불투명 텍스처 덩어리로 합치지 않는다. 챔버 내부에는 귀여운 흰 토끼를 별도의 고형 메시로 보존한다. 토끼의 얼굴 방향은 무기의 총구 방향과 정확히 같아야 한다. 최종 Blender 좌표에서 토끼 얼굴과 총구는 +Z, 위쪽은 +Y다. 총구에서 바라보는 정면에는 두 눈, 코, 양쪽 볼이 보여야 한다. 왼쪽과 오른쪽 무기 측면에서는 토끼가 각각 정확한 90도 프로필로 보여 한쪽 눈만 노출되어야 한다. 후면에서는 뒤통수와 꼬리만 보이고 눈·코·볼은 보이지 않아야 한다. 정면 얼굴과 옆면 얼굴을 동시에 중복하거나, 얼굴 파츠를 양쪽에 복제하거나, 여러 뷰를 한 표면에 융합하지 않는다.

방아쇠 오른손 실제 파지 중앙을 단일 root 원점과 RightHandGrip으로 사용한다. LeftHandGrip은 앞손 실제 접촉점에 두고, Muzzle은 총구 끝 중앙에 둔다. RightHandGrip, LeftHandGrip, Muzzle은 모두 root의 직계 자식이다. Muzzle의 local +Z는 발사 방향이다. 음수 또는 비균일 스케일 없이 모든 transform을 적용한다. FBX에는 Camera, Light, Armature, Collider를 포함하지 않는다.

재질은 Principled BSDF 기반으로 분리한다. P1 본체 텍스처 재질, 투명 얼음 재질, 흰 토끼, 눈, 코, 볼 재질의 이름을 명확히 유지한다. Unity 전달 시 외부 URP/Lit 재질로 1:1 remap할 수 있어야 한다.

최종 검증은 빈 Blender 씬 FBX 재임포트로 수행한다. 단일 root, 세 기준점, +Z 총구축, +Y 위축, triangle 수, unit positive transforms, non-null material slots, 투명 챔버와 내부 토끼의 분리, 토끼 얼굴 파츠가 +Z 반구에만 존재함을 확인한다.
