# 거너 54종 메시 관통 재검수 — 2026-09-20

> **산출물 정리:** 사용자 요청에 따라 최종 검수 시트 한 장만 남기고 촬영 원본·비교 이미지·갤러리·검사 데이터·임시 스크립트를 삭제했다. 아래 검증 결과는 정리 전 수행 기록이다.

사용자가 지적한 뇌전 코일·공허 연발포의 큰 관통을 포함해 54종 전체를 다시 확인했다. 1차 보고서의 마커 일치 검사만으로는 손바닥과 손가락 메시의 관통을 잡을 수 없었다. 이 문서와 아래 사진이 최종 저장 프리팹 기준이며, 이전 648장 검수 결과를 대체한다.

## 보정 내용

54종의 왼손 파지 중심·손목 회전을 조정했다. 손을 무기 내부에서 빼 실제 하부 지지면이나 측면 접촉면으로 옮겼다. 오른손 손잡이에 깊게 묻히던 9종도 RightHandGrip과 외형 루트의 부착 위치를 함께 조정했다. 원본 모델, 메시, 머터리얼, Muzzle, GUID, 컴포넌트와 이번 재검수 시작 시의 배율은 보존했다.

뇌전 코일은 하부 연결부를 감싸도록 손목을 세웠고, 공허 연발포는 손을 드럼 바깥 접촉면으로 옮겼다. 공업 스파크·설빙·소각 산탄총·용암 파쇄포처럼 몸체가 두꺼운 무기는 하부/측면의 접촉 깊이를 줄였다. 스마일 시그널은 하부 덮개 뒤쪽에서 손이 떠 보이는 위치를 재조정했다.

11종은 대기 또는 발사 중간에 팔 도달 범위를 벗어나는 현상이 추가로 확인되어 파지 위치와 손목 각도를 다시 맞추고 재촬영했다. 손을 억지로 늘리거나 IK 가중치를 강제로 고정하지 않았다. 기존 손가락 포즈를 사용하므로 손가락 끝의 작은 겹침과 완전히 감기지 않는 접촉은 허용했다.

1차 작업의 LeftElbowHint 이력 조사·위치 보정과 공격 복귀 후반의 IK 해제 처리는 유지했다. 이번 재검수에서 리그·뼈·모션을 추가 변경하지 않았다. 해당 근거는 [1차 기록](Gunner_Weapon_Grip_Fitting_Verification_2026-09-20.md)에 남겼다.

## 촬영과 육안 검토 범위

Unity 6000.3.22f1의 `Act1_Camp_MergeTest` 실제 Gunner Play Mode 객체에 저장 프리팹을 장착했다. 최종 촬영 중에는 임시 파지 보정을 적용하지 않았다.

- 보정 전: 54종 × 양손 근접 6각도 = 324장.
- 최종: 54종 × 대기·발사 시작·반동(Attack 0.25) 3자세 × 근접 6각도/상반신 6각도 = **1,944장**.
- 직접 육안 검토: 54종의 보정 전후 발사 근접 6각도 모아보기, 전체 무기의 3자세 상반신 비교와 반동 아래쪽 근접 사진. 문제가 발견된 무기는 개별 원본 및 추가 보정 사진을 다시 확인했다. 최종 추가 수정한 11종의 자세 비교와 뇌전 코일·공허 연발포·스마일 시그널의 근접 모아보기도 다시 확인했다.
- 1,944장을 모두 개별 확대해 확인했다는 의미는 아니다. 촬영 수, 육안 검토 범위, 수치 검사는 구분한다.

## 수치·런타임 검증

최종 162개 고정 자세 모두 IK 가중치 1, 왼손 접촉 마커 최대 오차 **0.02717mm**였다. 이는 목표 도달 여부를 검증하는 수치이며 메시 표면의 관통이 없다는 자동 판정은 아니다. 자세 검사 원본 (임시 자료 정리됨).

실제 `T_PlayerCombat.TryAttack` 54종 모두 공격 진입·대기 복귀를 확인했다. 발사 구간(Attack normalized time < 0.65, 전환 제외)의 IK 최저 가중치 1, 마커 최대 오차 0.01485mm였다. 공격·대기 복귀 기록은 런타임 검사 (임시 자료 정리됨)에 기록한다. 사진 촬영이 프레임에 영향을 주지 않도록 별도 실행했다.

54개 프리팹의 허용 Transform 외 필드 보존 검사, 양손 Grip 존재, Missing Script 및 null 머터리얼 검사를 수행했다. 자산 보존 검사 (임시 자료 정리됨), 참조 검사 (임시 자료 정리됨).

## 검증 한계

이번 대상은 무기 장착과 파지 외형이다. 개별 손가락 애니메이션 제작, 모든 이동·피격·사망 모션, 장비 UI와 멀티플레이 동기화는 검증 범위에 포함하지 않았다. 공격 복귀 후반에 팔 도달 범위를 벗어나면 기존 보정 코드가 왼손 IK를 해제하므로 그 구간에는 손이 무기에서 떨어질 수 있다.

Play Mode에서는 기존 `EnemySystem : EnemyPool 의 EnemyDefSo 가 비어 있습니다.` 오류가 발생한다. 무기 파지와 별개의 기존 데이터 문제로 남겼다. 임시 Editor 촬영 도구 제거 후 컴파일 완료, Console 오류 0, Gunner 리그 무결성 검사 통과를 확인했다. 원래 열려 있던 깨끗한 Act1_Stage1 Scene으로 복원했다. 사용자 Scene을 저장하지 않았으며 Commit·Push는 하지 않았다. 김성우 개인 구현 로그의 같은 작업 항목을 갱신했다.
