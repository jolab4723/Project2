# 고유효과 범위·디버프 VFX 교차검증 목록 (2026-10-06)

다른 AI가 이번에 새로 만들거나 수정한 이펙트 디자인을 독립적으로 검토하기 위한 목록이다. 판정은 실제 Unity 화면(Game 뷰, Act1 맵 조명·Bloom 포함) 기준으로 하고, 이 문서의 의도 설명보다 화면을 우선한다.

## 1. 공통 품질 기준 (사용자 확정)

- 하한: 기존 고유효과 VFX(`Assets/SW/Resources/UniqueEffectVFX`의 중력 우물·특이점·헬로 월드 오라) 이상, 버프 성격은 파이터 궁극기 버프(`Assets/Resources/Effects/Fighter_Effects/EffectPrefab/F_S4_E0_1_Effect.prefab`) 수준.
- 상한: 전투 화면에서 너무 튀지 않는 자연스러운 톤. 과한 밝기·밀도, 바닥이나 캐릭터를 가리는 진한 색은 실패로 본다. 저퀄과 과잉 둘 다 실패.
- 테두리 선만 있는 원, TMP 글자, 단순 LineRenderer 같은 임시 표시는 완료로 보지 않는다.
- 시간제 버프나 공격 판정이 아닌 상시 범위 표시에는 크기가 변하는 링(펄스·수축 파동)을 쓰지 않는다.
- 4인 멀티에서 같은 효과가 여러 개 겹쳐도 화면을 덮지 않아야 한다. 다른 플레이어의 범위는 본인 범위보다 0.55배 밝기로 그린다.

## 3. 이펙트별 의도와 검토 질문

### E1 아군 범위 오라 바닥
- 구성: 아주 옅은 바닥 채움, 가장자리 테두리(얇은 선과 천천히 흐르는 대시), 낮은 경계 빛 장막(높이 약 0.3m), 가장자리에서 오르는 빛 입자, 드문 상승 줄기. 색은 오라 SO의 `areaVisualColor`를 따른다(세 오라 모두 하늘색).
- 확인할 점: 12m 반경에서 바닥을 가리지 않는가, 테두리·장막이 탑뷰에서 두꺼운 발광 띠로 보이지 않는가, 세 오라가 겹칠 때도 화면이 정돈돼 보이는가, 플레이어 몸에 붙는 버프 오라(`UEVFX_*Buff`)와 역할이 구분되는가.

### E2 적 대상 범위 오라 바닥
- 구성: E1과 같은 바닥·테두리에 안쪽을 향한 화살표 무늬가 중심 쪽으로 흐르고, 장막 무늬가 아래로 흐르며, 가장자리에서 안쪽으로 빨려 드는 줄기와 내려앉는 입자가 있다. 보라색(SO 색).
- 확인할 점: 아군 범위와 한눈에 구분되는가(색과 흐름 방향), 화살표 무늬가 과하지 않은가, 8m 반경이 화면 대부분을 덮지 않는가.

### E3 적 대상 오라의 둔화 표시
- 기존 공용 둔화 연출을 범위 안 적에게 상시 재생한다. 새 연출은 만들지 않았다.
- 확인할 점: 보스처럼 큰 적에서 공용 둔화 연출이 과하게 크지 않은가, 범위를 드나들 때 깜빡이지 않는가.

### E4 일식 기관 장판 (재설계)
- 모티프: 무기 기관부 옆 원형 문양(검은 하우징 속 주황 용융 코어, 얇은 주황 링, 황동 테와 십자 눈금 4개)과 금환 일식 사진. 장판은 "무기 코어 문양이 바닥에 펼쳐지며 태양이 가려지는 순간"이다.
- 구성: 무늬 없는 반투명 검정 원판, 가장자리의 얇은 백금색 링과 좁은 주황 글로우(색은 텍스처에 직접 넣어 진한 적색 번짐을 막음, 밝기만 약하게 일렁임), 링 바로 안쪽의 어두운 황동 테와 눈금 4개, 링 위에서만 드문드문 오르는 작은 불꽃과 불티. 용암 균열·연기·화염 장막 벽은 과해서 제거했다.
- 명중 연출(약 0.55초): 중심 코어 섬광, 지면 충격파 1회, 불티 분출 → 원판·링·황동 테가 중심에서 반경까지 번지며 나타남 → 불꽃 시작. 종료 0.45초 전부터 흐려지고 불꽃 방출이 멈춘다.
- 확인할 점: 레퍼런스처럼 단순하고 고급스러운가, 무기 문양과 같은 계열로 읽히는가, 바닥에 뚝 생기거나 뚝 사라지는 느낌이 남아 있는가, 화상 지대라는 위험이 충분히 전달되는가, 중력 우물·특이점 장판과 밝기·밀도가 비슷한가, 최대 2개가 겹칠 때 과하지 않은가.

### E5 스마일 시그널 표식
- 구성: 머리 위 노란 조준 레티클. 바깥 브래킷과 네 방향 화살촉만 천천히 회전하고 가운데 스마일 얼굴은 항상 똑바로 고정된다(사용자 지정). 등장 시 잠금 축소 연출, 약한 메아리 고리, 반짝임, 발밑 회전 잠금 브래킷.
- 확인할 점: 표식이 붙은 적을 아군이 바로 찾을 수 있는가, 거너 스킬의 공용 Marked 연출(글리터 폭탄)과 혼동되지 않는가, 드론·보스 크기에서 비율이 맞는가.

### E6 초냉매 냉각 누적
- 구성: 단계마다 몸 주위 120도 간격으로 Blender 얼음 결정 메시 1개씩(최대 3개, 천천히 자전), 결정 글로우, 등장 시 얼음 파편, 몸 주위로 내리는 서리 입자.
- 확인할 점: 1/2/3단계를 숫자 없이 구분할 수 있는가, 빙결 상태이상의 공용 연출과 겹칠 때 어색하지 않은가, 결정이 너무 하얗게 과노출되지 않는가.

### E7 코어 브레이커 방어 감소
- 구성: 머리 위 깨진 육각 방패 + 하향 화살표 아이콘(적주황), 등장 팝, 아이콘 글로우, 몸 주위를 도는 Blender 방패 파편 5개, 아래로 떨어지는 불티.
- 확인할 점: 방어 감소라는 의미가 직관적인가, E5·E6와 동시에 붙을 때 머리 위가 지저분해지지 않는가(머리 위는 레티클과 아이콘이 세로로 쌓이고, 냉각 결정은 몸 주위에 배치됨).

## 4. 확인 방법

1. Editor에서 `Act1_` 맵을 열고 Play한 뒤, Game 뷰를 Bloom이 켜진 상태로 캡처한다(카메라→RenderTexture 수동 렌더는 색이 달라질 수 있어 쓰지 않는다).
2. 범위는 `PlayerRelicEffectRuntime.CreateAura`(유물 오라 생성 경로), 장판은 `PlayerGrenadeEffect.CreateRing(parent, "SunfallBurnFieldVisual", 3f, color)`, 표식은 적 오브젝트에 `EnemyEffectIndicator`를 붙이고 `SetSupportMark(true, 60)`, `SetCooling(1~3, 60)`, `SetDefenseDown(true)`로 띄울 수 있다.
3. 비교 대상으로 같은 화면에 `UEVFX_GravityWellField`(반경 3.5 배율), 파이터 궁극기 버프 `F_S4_E0_1_Effect`, 헬로 월드 버프 오라 `UEVFX_HelloWorldBeaconBuff`를 함께 띄운다.
4. 실제 게임 탑뷰 카메라 구도와 가까운 근접 구도 두 가지로 본다. 4인 겹침은 범위 오라 3개(12/6/8m)와 일식 장판 2개를 동시에 띄워서 본다.

## 5. 범위 밖과 알려진 제약

- 색은 데이터 SO 값이며 아군 범위 오라 세 개가 같은 하늘색이다. 오라별 색 구분은 데이터 변경이 필요해 이번 범위에서 제외했다.
- 플레이어 시한·조건부 버프(약 40종)의 월드 표시는 이번 범위가 아니다(HUD 아이콘만 있음).
- 중력 우물·특이점 장판과 플레이어 몸 버프 오라는 기존 VFX이며, 비교 기준으로만 본다.
