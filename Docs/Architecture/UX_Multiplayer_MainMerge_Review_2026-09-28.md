사용자가 보스뿐 아니라 전체 적과 두 플레이어 직업을 포함한다고 명확히 지정하여 다시 조사했다. 앞선 40/217항목 통과를 게임 전체의 싱글·멀티 동일성 보장으로 해석하면 안 된다.
