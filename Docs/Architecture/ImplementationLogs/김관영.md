## 2. 2026-09-07 작업 상세

### 무엇을 작업했나

- Unity Editor에서 LobbySeane의 기존 UI를 사용해 YOU, HOST, NOT READY, EMPTY / WAITING 표시를 연결했다. 슬롯 표시 순서는 화면 왼쪽부터 1~4번이다.
- 하단에 나가기, 캐릭터 변경, 큰 READY, 방장용 게임 시작 버튼을 배치하고 로비 컨트롤러의 버튼 6개와 텍스트 참조를 연결했다.
- LobbyPanel을 Canvas 전체에 맞추고 CanvasScaler는 1920×1080 기준으로 설정했다. 로비 한글 텍스트는 기존 Pretendard 폰트를 참조한다.
- 선택 화면 재진입 시 ReplayIn으로 숨김 위치부터 슬라이드를 다시 재생하고, 중복 Tween과 비활성화된 UI의 Tween을 정리한다.
- 게임 시작 버튼은 로컬 방장에게만 표시하며 모든 참여자가 READY일 때 활성화한다. 나가기는 로컬 미리보기 참여자 목록을 비운 뒤 선택 화면으로 복귀한다.
- 수동 모델 4개는 보존했다. lineupView 참조는 비워 두었으며 자동 생성 컴포넌트는 없다. 씬은 Unity Editor에서 저장했고 YAML을 직접 편집하지 않았다.

### 기존 기능이 깨질 가능성

- KY_SlideAnimator의 Tween 중복 방지·비활성화 정리는 해당 컴포넌트의 다른 UI 사용처에도 적용된다. 이번 검증은 로비와 선택 화면에 한정한다.
- 검증 중 환경설정 저장 버튼에서 `Core.SettingManager.Save`의 null 경로 예외가 관찰됐다. 다른 담당자의 코드는 수정하지 않았고 설정 저장 문제는 남아 있다. 마지막 로비 검증에서는 설정 저장을 실행하지 않았다.
- Unity가 생성한 씬 직렬화의 빈 `m_Name` 행에 trailing whitespace가 있다. YAML 직접 편집 금지에 따라 정리하지 않았다. 코드 변경에는 whitespace 오류가 없다.

### 팀과 상의할 내용

- 실제 멀티플레이 단계에서 참여자 데이터 공급, 나가기 연결 해제, GameStartRequested 이후 게임 진입을 연결한다.

### 아직 하지 않은 일

- 싱글/멀티 분기와 실제 네트워크 권한·동기화.
- 수동 모델은 선택 클래스나 EMPTY 상태에 따라 교체·숨김 처리하지 않는다. 현재 모델 배치는 시각 미리보기이며 UI 데이터만 갱신한다.
- 16:9 이외 화면 비율과 실제 다중 클라이언트 검증.

## 2-3. 2026-09-07 싱글 준비 화면 분리

- Unity AssetDatabase로 기존 LobbySeane을 MultiplayerLobbySeane으로 이동하여 GUID를 유지하고, SinglePlayerLobbySeane을 복제·편집했다.
- 싱글 씬에서 멀티 슬롯과 컨트롤러를 제거하고 캐릭터 선택·상세 정보·미리보기·회전·팝업 스크립트를 재사용했다. 화면 오브젝트는 씬별 복사본이며 공통 프리팹으로 추출한 상태는 아니다.

- 타이틀 버튼의 대상 이름을 SinglePlayerLobbySeane / MultiplayerLobbySeane으로 변경했다. Build Settings는 변경하지 않았다.
- 컴파일 후 Console 오류·경고 0개, 싱글 컨트롤러 참조 누락 0개, Canvas Missing Script 0개를 확인했다. Play Mode에서 Fighter 선택·확정 → 준비 화면 및 시작 미연결 안내를 확인하고 캡처를 검토했다.
- 사용자 테스트 대기: Gunner 선택, 캐릭터 변경 반복, 드래그 감도, 팝업 조작. 실제 시작 이벤트 수신 시스템과 씬 간 이동은 미연결·미검증이다. 패시브 효과/저장과 환경설정 초기화의 기존 제한도 유지된다.

- 앞선 별도 준비 화면을 제거하고, 멀티 로비의 3D 배경과 발판을 재사용해 중앙 캐릭터 한 명을 선택하는 화면으로 변경했다.

- 비활성 정보창에서도 스탯을 갱신할 수 있도록 KY_CharacterStatRadarChart.SetValues에서 비활성 상태의 값을 저장하도록 수정했다.
- Play Mode에서 Gunner 선택, 상세 창 열기, Gunner ID 시작 이벤트 전달과 화면 캡처를 확인했다. 마지막 Console 오류·경고 0개, 씬 Missing Script 0개였다.
- 반복적인 마우스 조작·회전 감도·팝업 테스트는 사용자 확인 대기다. 실제 게임 시작과 Build Settings 연결은 담당자 작업으로 남긴다.

- 후속 수정: 캐릭터 정보창을 상시 표시하고 열기·닫기 버튼을 제거했다. 기본 Fighter 선택을 없애고 모델 숨김·선택 안내·시작 버튼 비활성 상태로 저장했다. Play Mode에서 초기 미선택과 정보창 표시, 캐릭터 선택 후 시작 버튼 활성화 및 Console 오류·경고 0개를 확인했다.

- 후속 수정: 싱글 캐릭터 정보 패널에 KY_SlideAnimator를 연결했다. 첫 CharacterSelected 이벤트에서만 패널을 활성화하고 ReplayIn을 실행하며, 이후 다른 캐릭터를 선택하면 열린 패널의 내용만 갱신한다. 초기 패널 비활성 상태와 첫 선택 후 표시, 두 번째 선택 시 재진입 없음, Console 오류·경고 0개를 확인했다.
