## 2. 2026-07-16 작업 상세

### 무엇을 작업했나

- 노드를 선택하면 해당 노드에서 도달할 수 없는 미래 노드와 라인이 즉시 갱신되도록 선택 흐름을 보완했다.
- 노드 Reticle이 좁혀진 뒤 좌우 Bracket이 최종 간격의 일정 비율만큼 반복 왕복하도록 애니메이션을 추가했다.
- 도달할 수 없는 노드의 Icon과 Background가 지정된 Tint로 부드럽게 전환되도록 수정했다.
- 도달할 수 없는 라인의 색상과 알파가 부드럽게 전환되도록 수정했다.
- 노드와 라인의 `tintTransitionDuration` 기본값을 0.5초로 설정하고 Inspector에서 각각 조절할 수 있게 했다.
- 전환 도중 경로 상태가 다시 바뀌면 현재 색상과 알파에서 새로운 목표 상태로 이어지도록 처리했다.
