## 검토 시 유의할 사항

- Act2는 원본 싱글 타임라인의 짧은 이동과 카메라를 유지한다. 사용자의 최종 지시대로 네 대역이 함께 이동하며, 손 위 고정·시간 연장·추적 카메라는 추가하지 않는다.
- 전투 가속과 일부 효과 검사는 외부 도구에서 정상 피해 처리·서버 API를 호출한 이벤트 경계 검사다. 수동 입력을 포함하는 전체 플레이와 구분한다.
- 신규 Firebase 계정의 첫 업로드와 서로 다른 실제 계정 간 전환, 네트워크 장애 중 업로드는 실행하지 않았다. 기존 실제 인증 세션·로그아웃과 테스트 계정 멀티 검증의 범위를 구분한다.
- 퀘스트 부분 보상 저장·재로드·잔여 보상 재시도는 확인했다. 운영 저장장치 장애 및 구형 저장 파일 전체 조합의 전수 검사는 아니다.
- 기존 외부 보스 셰이더 오류를 새 C# 컴파일 오류와 구분한다. 빌드 성공 여부와 오류 로그 개수를 함께 기록한다.
- 시작 전 존재하던 Addressables link.xml 삭제와 원본 계획 문서는 보존한다. 검증 후 임시 설정·저장 데이터·Editor 생성 변경을 정리한다.
