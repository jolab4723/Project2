## 변경 내용

각 무기의 실제 피스톨 손잡이와 앞손 접촉면을 개별 확인하고 `RightHandGrip`, `LeftHandGrip`의 위치·회전을 맞췄다. 수직 앞손잡이는 손잡이 축을 따라, 별도 앞손잡이가 없는 무기는 하부 핸드가드·지지면을 받치도록 조정했다. 손목 방향도 접촉면에 맞췄다.

현재 Presenter는 오른손 Grip을 매 프레임 자동 정렬하지 않는다. 따라서 오른손의 손잡이 중심을 기준으로 계산한 외형 루트 위치·회전을 프리팹에 함께 저장했다. 왼손 Grip은 캐릭터의 `LeftWeaponPalmContact` 접촉면 기준이므로, 메시 손잡이 중심 좌표와 수치가 다를 수 있다. 표의 앞손 좌표는 메시의 파지 중심이며 실제 저장된 Grip은 기존 손 접촉면 오프셋을 반영한 값이다.

### 팔꿈치와 공격 복귀

`Gunner.prefab` 변경은 `LeftElbowHint`의 로컬 위치 한 줄뿐이다: `(-0.27629, 1.0799, 0.32479)` → `(-0.23, 0.83, 0.18)`. 기존에 높이 들리던 왼팔 팔꿈치를 낮췄다.

사용자가 김성우 작성분에 한해 수정을 허용했으므로 먼저 Git 원본을 직접 대조했다. 로컬 모든 ref의 해당 프리팹 162개 버전, 그중 JYJ 커밋 56개와 병합의 모든 부모를 확인했다. 힌트는 8/22 김성우 계정의 추가분이며, 힌트가 있는 118개 버전에서 해당 설정은 동일했다. JYJ의 손 타깃·무기 소켓 변경은 별도로 확인했다. 커밋별 근거와 조사 범위 (임시 자료 정리됨).

최신 공격 모션은 복귀 후반에 총을 아래로 내려 왼팔 도달 범위를 벗어난다. `PlayerWeaponVisualPresenter.UpdateGunnerLeftHandIkWeight`에서 이때만 도달 거리에 따라 IK를 점진적으로 해제한다. 도달 가능한 발사·반동 구간은 가중치 1을 유지하며, 대기로 돌아오면 다시 잡는다. 기존 모션 클립이나 소켓은 수정하지 않았다.

같은 공격 후반 자세에서 IK 강제 유지와 해제 비교 (임시 이미지 정리됨)

비교 사진은 Attack normalized time 0.875에 고정한 진단용 자세다. 왼쪽은 이전 동작을 재현하기 위해 IK=1을 강제한 것이고, 오른쪽은 새 도달 거리 처리를 적용했다. 실제 시간 흐름 검증은 아래 별도 54회 공격 기록으로 확인했다.

## 실제 검증

- Unity 6000.3.22f1, `Act1_Camp_MergeTest`의 실제 Gunner Play Mode 객체에서 수행했다. 저장된 프리팹을 재장착한 뒤 촬영했으며 촬영 단계에서 파지값을 임시 보정하지 않았다.
- 54종 × 대기/발사 시작 2자세 × 오른쪽·왼쪽·정면·오른쪽 사선·왼쪽 사선·낮은 사선 6각도 = **648장**. 무기마다 12장과 2개의 모아보기 이미지를 제공한다.
- 각 무기의 형상과 양손 위치를 다각도로 검토했다. 사진 촬영 중 다른 무기가 겹치지 않도록 단독 외형 상태를 확인했다.
- 저장된 108개 자세에서 왼손 접촉 마커 최대 오차 **0.04989mm**, 오른손 기준 중심 최대 오차 **0.00050mm**, IK 가중치 전부 1. 수치는 손 접촉 기준점의 거리이며 손가락 표면 전체의 관통·밀착 정도를 뜻하지 않는다.
- `T_PlayerCombat.TryAttack` 실제 호출 54종 전부 공격 진입과 대기 복귀를 확인했다. 촬영으로 프레임 시간이 늘어나는 영향을 피하기 위해 이 검증은 별도의 실시간 기록으로 수행했다.
- 발사·반동 검증 구간(Attack, transition=false, normalized time < 0.65)의 왼손 최대 오차 **0.03113mm**, 최소 IK 가중치 1. Workspark·Sulbing의 반동 중 도달 초과를 추가 발견해 앞손 파지점을 실제 지지면 안에서 당긴 뒤 재검증했다. SmileSignal도 함께 재검증했다.
- 공격 후반에는 54종 모두 도달 범위에 따른 손 놓기와 대기 복귀를 확인했다. 이 구간의 손-무기 간격을 파지 오차 0으로 주장하지 않는다.
- 54개 프리팹의 두 Grip, Missing Script 0, null 머터리얼 0. 원본 GUID·모델 자식 Transform·메시·머터리얼·Muzzle 로컬값·컴포넌트 구성이 전후 동일하다.
- `GunnerWeaponRigIntegrityGuard.ValidateOrThrow()` 통과. 임시 촬영 Editor 스크립트 제거 후 컴파일 완료, Console 오류 0 확인. Play Mode에서 기존 `EnemyPool 의 EnemyDefSo 가 비어 있습니다` 오류는 발생했으며 이번 수정으로 해결한 것으로 간주하지 않는다.
- 처음 열려 있던 `Act1_Stage1`을 Edit Mode의 clean 상태로 복원했다. 테스트 씬은 저장하지 않았다. Commit/Push는 하지 않았다.

## 검증 범위와 남은 한계

손가락별 애니메이션은 기존 클립을 유지했다. 특히 두꺼운 지지면·장식이 있는 무기는 손바닥 지지가 맞더라도 손가락이 손잡이를 완전히 감싸는 모양까지는 보장하지 않는다. 이를 더 정교하게 만들려면 별도의 손가락 포즈 작업이 필요하다.

54종은 Presenter의 실제 외형 교체 경로로 장착했다. 각 아이템을 인벤토리에서 획득·장비 슬롯에 넣는 UI 전체 흐름과 개별 아이템 능력치는 이번 전수 검증 범위가 아니다. 기본 공격, 대기 및 공격 복귀를 확인했으며 모든 스킬·회피·이동 방향 조합과 네트워크 원격 캐릭터는 전수 검증하지 않았다.

테스트 씬의 소켓에는 Presenter가 소유하지 않은 기존 외형이 별도로 남아 있어 촬영 때 비활성화했다. 씬 변경은 저장하지 않았으며, 해당 씬 배치의 중복 외형 자체를 이번 변경으로 해결했다고 주장하지 않는다.
