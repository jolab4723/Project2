# 스킬 연계 아이템 기획안 (초안)

작성: 김성우(SW), 2026-10-19. 상태: 기획 검토용이며 테이블과 에셋에는 아직 반영하지 않았다.
함께 볼 문서: [스킬_아이템_연계_A안_설계.md](스킬_아이템_연계_A안_설계.md)

## 0. 목적과 원칙

목적: 지금은 기본 공격 + 스탯 빌드 하나로 수렴한다. 파이터·거너의 스킬마다 그 스킬을 중심으로 굴러가는 빌드 축을 하나 이상 만든다.

원칙(ponytail + SOLID)
- **새 3D 모델을 최소화한다.** 신규 무기는 모델·외형 프리팹·아이콘이 필요하다. 그래서 무기 쪽은 고유효과가 비어 있는 기존 레어 무기 14종 중 6종에 새 효과를 붙인다. 신규 아이템은 아이콘만 있으면 되는 유물과 방어구로 만든다.
- **기존 효과 유형을 먼저 쓴다.** 16종 중 12종은 이미 있는 효과 유형(`PassiveBuff`, `TriggeredBuff`, `DodgePreparedAttack`)의 새 데이터 행이다.
- **새 효과 유형은 두 개만 만든다.** 각 유형이 아이템 둘 이상을 받거나, 다른 방법으로는 만들 수 없는 빌드를 연다(개방·폐쇄: 이후 아이템은 데이터 행만 추가).
- **스킬 쪽 변경은 기존 인터페이스로 한다.** 처치 시 쿨타임 감소는 이미 구현체가 둘인 `ISkillController`에 메서드 하나를 추가해 처리한다. 아이템 코드는 구체 컨트롤러를 모른다(의존 역전).

## 1. 구현 단계

| 단계 | 필요 조건 | 작업 |
|---|---|---|
| T0 | 없음 | 테이블에 행만 추가 |
| T1 | A1 (피해 출처 열) | 테이블에 행 추가, `hitSource=Skill` |
| T2 | A2 (`OnSkillCast`) | 테이블에 행 추가, `triggerCondition=OnSkillCast` |
| T3 | A3 (대시·백스탭 = 회피) | 기존 회피 트리거 아이템이 그대로 스킬과 연계됨. 추가 작업 없음 |
| T4 | 신규 효과 유형 | 코드 추가 후 행 추가 |

## 2. 빌드 축별 아이템

표기: 계수는 테이블의 `coefficients`처럼 `;`로 구분한다. 가격은 무기 `sellPrice`, 그 외 `itemPrice`다.

## 3. 신규 효과 유형 (T4)

| 유형 | 사용 아이템 | 필요한 변경 | 담당 |
|---|---|---|---|
| `SkillCooldownOnKillUniqueEffectSO` | 과부하 심장, 충전 회로 | `ISkillController.ReduceCooldown(int index, float seconds)` 추가. Fighter·Gunner 컨트롤러 구현(스택형은 충전 진행). 처치 트리거 경로에서 호출 | 인터페이스·컨트롤러 WJ, 효과 SO·실행 SW |
| `MarkedDamageBonusUniqueEffectSO` | 표적 분석 렌즈 | 피해 계산에서 대상이 표식 상태면 공격자 배율 추가 | 효과 SO·피해 해석기 SW, 표식 상태 조회 BH(`WBH_StatusEffectController`, 읽기만) |
| `ElementResonator` 계열 | 원소 공명기 | A4 이후 별도 설계 | 미정 |

멀티 기준: 세 유형 모두 기존 고유효과처럼 서버(`CanExecute`)에서만 실행한다. 쿨타임 감소는 서버 컨트롤러에서 일어나고, 클라이언트 HUD는 기존 쿨타임 동기화를 따른다(구현 시 확인).

## 5. 밸런스 메모

- **스킬 비중이 먼저입니다.** 스킬 딜이 기본 공격의 1/3이라, 아이템만으로는 스킬 빌드가 기본 공격 빌드를 이기기 어렵다. A안 설계 7절 C2(스킬 계수·마나 조정)와 함께 적용해야 한다.
- **치명 피해 기반 아이템은 보류합니다.** 치명 배율이 1.10~1.29배라서 치명 피해 효과의 가치가 거의 없다. 치명 배율 조정(A안 설계 7절 C1) 이후에 다시 본다. 치명 확률은 치명타 트리거 발동률에 쓰이므로 문제없다.
- **광역 스킬 트리거는 쿨이 필수입니다.** `hitSource=Skill` 행은 쿨타임이나 최대 스택이 반드시 있어야 한다(A1 임포터 검증 규칙).
- **쿨감 상한은 70%입니다.** 아드레날린 주입기(10) + 바람의 인도(5) + 관리자 키(8) + 패시브(최대 20) + 서브옵션(2씩)을 쌓아도 상한에 걸리지 않지만, 차원문 망토·차원의 나침반의 회피 시 쿨감이 겹치면 순간적으로 50%를 넘는다. 플레이 테스트에서 확인한다.
- **가격 기준:** 5-1절의 등급 기준표를 따른다.

## 5-1. 등급별 효과 밸런스 검토

`ItemDataTable.xlsx`(무기 102, 방어구 41, 유물 16)와 `UniqueEffectTable.xlsx`(100행)를 같은 가정으로 환산해 등급끼리 비교했다. 데이터 비교용 추정이며 실제 플레이 측정이 아니다. 숫자를 확정하기 전에 고정 허수아비 앞에서 10초 피해량을 재서 맞춘다.

**환산 가정 (10레벨)**
- 기본 공격력 파이터 101, 거너 117. 적 방어력 45, 플레이어 관통 10. 치명 확률 14%, 치명 배율 1.19.
- 전투 피해의 75%는 기본 공격, 25%는 스킬이다. 공속·일반 공격 피해·속성 보너스는 기본 공격 몫에만 붙는다. 속성 보너스는 무기 속성이 같을 때만 센다.
- 발동 가동률: 적중 시 90%, 치명타 시 지속/(쿨+3.8초), 처치 시 지속/max(쿨, 2.5초), 피격 시 지속/(쿨+3초), 회피 시 지속/max(쿨, 5초). 체력 조건형은 30% 이하 10%, 35% 이하 12%, 50% 이하 25%, 90% 이상 40%.
- 기계형 효과(연쇄 번개, 추가타, 폭발 등)는 적 2~3명 무리 기준으로 손으로 환산했다. 감속·빙결·보호막은 공격 지수에 넣지 않았다.
- **공격 지수** = (기본 공격력 + 무기 공격력) / (기본 공격력 + 10) × (1 + 고유효과 기여). 1.00은 공격력 10짜리 일반 무기다.

## 6. 반영 절차

1. `ItemDataTable.xlsx`, `UniqueEffectTable.xlsx`에 행을 추가하고, `ItemDataLabel`, `UniqueEffectLabel`에 4개 언어 문구를 추가한다.
2. `DataLoader/Item Data Table/0. Run All Steps`로 SO를 생성·갱신한다.
3. 신규 유물·방어구는 아이콘 원본을 `Assets/Resources/Images/Item/OriginalImage`에 `{itemId}.png`로 넣고, 인벤토리 무기 아이콘 변환기로 일괄 변환한다(무기가 아니어도 같은 아이콘 규격을 쓰는지 구현 시 확인).
4. 기존 무기 6종은 `uniqueEffectId`만 채우면 된다. 외형 프리팹과 아이콘은 그대로 쓴다.
5. 드롭 테이블은 등급 가중치를 그대로 쓰므로 수정할 필요가 없다.

## 7. 열린 결정

- 기존 레어 무기 6종에 효과를 붙일지, 아니면 같은 효과로 신규 무기를 만들지(모델 제작 비용)
- `SkillCooldownOnKill` 쿨 감소량(궁극기 1초, 아크 2초)
- 원소 공명기를 이번 범위에 넣을지
- 5-1절 기존 아이템 조정(B1~B10)을 이번에 함께 반영할지, A안 7절 C1·C2와 적 쪽 수정(C5~C8) 이후로 미룰지
