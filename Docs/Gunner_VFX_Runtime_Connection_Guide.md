# 거너 무기 VFX 연결과 테스트 가이드

이 문서는 거너 무기의 `총구 → 날아가는 탄환 → 명중` 연출이 실제 공격 코드에서 어떻게 이어지는지 설명합니다.
무기 VFX를 교체하거나 새 무기를 추가할 때 아래 순서만 확인하면 됩니다.

## 1. 공격할 때 실행되는 순서

1. `PlayerWeaponVisualPresenter`가 현재 장착한 무기 외형을 캐릭터의 `WeaponSocket` 아래에 표시합니다.
2. `T_PlayerCombat`이 손에 보이는 무기에서 `GunnerWeaponVfxBinding`을 찾습니다.
3. `GunnerWeaponVfxBinding`에 저장된 `Muzzle` 위치에서 총구 연출을 재생합니다.
4. `WBH_ProjectileSpawner`가 기존 투사체 풀에서 투사체 하나를 빌립니다.
5. 라이플·유탄은 `WBH_Projectile`이 빌린 투사체에 해당 무기의 비행 VFX를 붙이고 앞으로 이동시킵니다. 산탄총은 중앙 투사체를 만들지 않습니다.
6. 투사체가 부딪히거나 유탄이 폭발하면 해당 무기의 명중 VFX를 재생합니다. 산탄총은 실제 부채꼴 판정에 맞은 적마다 바로 재생합니다.
7. 투사체가 풀로 돌아갈 때 이전 입자와 꼬리를 모두 지웁니다. 다음 발사에서는 같은 투사체를 깨끗한 상태로 다시 씁니다.

중요: 새 VFX는 모양만 담당합니다. 이동, 충돌, 데미지와 폭발 범위는 기존 전투 코드가 계속 담당합니다.

## 2. GunnerWeaponVfxBinding 필드

모든 거너 무기 외형 프리팹의 루트에는 `GunnerWeaponVfxBinding`이 하나 있습니다.

- `Weapon Type`: 실제 공격 방식입니다. `Rifle`, `Shotgun`, `GrenadeLauncher` 중 하나를 고릅니다.
- `Muzzle`: 총열 끝에 있는 기준점입니다. 무기 루트 바로 아래의 `Muzzle`을 연결합니다.
- `Muzzle Visual Prefab`: 발사 순간 총구에서 짧게 보이는 연출입니다.
- `Projectile Visual Prefab`: 라이플·유탄의 탄환과 함께 날아가는 외형과 꼬리 연출입니다. 산탄총 18종은 중앙 탄환을 사용하지 않으므로 비워 둡니다.
- `Impact Visual Prefab`: 벽, 적 또는 지면에 닿았을 때 보이는 연출입니다.

`Muzzle`의 파란 축인 `+Z`가 탄환이 나가는 방향을 향해야 합니다. 위치가 맞아도 축이 옆이나 뒤를 보면 총구 연출과 탄환이 돌아가 보입니다.

## 3. 무기 종류별 데미지 처리

### 라이플

투사체가 이동하다가 적과 충돌하면 기존 단일 대상 데미지를 줍니다. 비행 VFX와 명중 VFX는 이 투사체를 따라갑니다.

### 산탄총과 화염 분사기

실제 데미지는 기존 `SectorAttack`이 전방 10m, 총 90도 부채꼴 안의 대상에게 한 번 처리합니다. 중앙으로 날아가는 시각용 투사체는 만들지 않습니다.
명중 VFX는 실제 부채꼴 판정에 맞은 각 적 위치에서 바로 재생됩니다. 따라서 부채꼴 총구 연출과 한 발짜리 탄환이 겹치거나, 같은 공격의 데미지와 명중 연출이 두 번 나오지 않습니다.

산탄총 18종은 모두 중앙 탄체 없이 총구 VFX만으로 실제 판정과 같은 10m·90도 부채꼴을 보여 줍니다. 일반·얼음·전기 계열은 두 겹의 짧은 Burst가 0.135초 안에 확산하고, 화염 분사기·인시너레이터·마그마크러셔는 폭죽처럼 한꺼번에 터지지 않도록 0.3~0.36초 동안 이어지는 화염 제트로 같은 범위를 채웁니다. 얼음과 전기는 기존 결정·번개 재질과 속성색을 그대로 사용합니다.

모든 계열의 최장 설정 이동값은 10m를 넘지 않습니다. 무기 외형의 축소 스케일이 파티클 이동거리까지 줄이지 않도록 설정했으므로 실제 장착 상태에서도 같은 범위를 유지합니다. 별도의 좌우 이동 탄환, Collider, Rigidbody, 데미지 또는 추가 투사체 풀은 사용하지 않습니다.

화염 분사기도 근접 화염 장판이 아니라, 총구에서 발사되어 앞으로 날아가는 거너 투사체로 표시됩니다.

### 유탄 발사기

기존 포물선 이동과 광역 데미지를 그대로 씁니다. 유탄이 도착하거나 장애물에 닿으면 기존 폭발 효과와 무기별 명중 VFX가 함께 재생됩니다.

## 4. 새 무기 VFX를 연결하는 순서

1. 해당 무기의 `{itemId}_WeaponVisual.prefab`을 엽니다.
2. 루트 바로 아래에 `Muzzle`이 하나 있는지 확인합니다.
3. `Muzzle`을 실제 총열 끝에 놓고 파란 축 `+Z`를 발사 방향으로 맞춥니다.
4. 루트의 `GunnerWeaponVfxBinding`에서 무기 종류와 총구·비행·명중 프리팹을 연결합니다.
5. 비행 및 총구 프리팹에는 `Collider`, `Rigidbody`, 데미지 스크립트 또는 Light를 넣지 않습니다.
6. Play Mode에서 무기를 장착한 뒤 총구 위치, 탄환 방향, 충돌 명중과 풀 반환 후 잔류를 확인합니다.

새 무기를 추가할 때 `T_PlayerCombat`, `WBH_ProjectileSpawner`, `WBH_Projectile`에 무기 이름별 분기를 더 만들 필요는 없습니다.
무기 외형의 `GunnerWeaponVfxBinding`만 올바르게 연결하면 같은 실행 흐름을 사용합니다.

## 5. Act1_Camp_MergeTest에서 바로 확인하는 방법

1. `Assets/SW/Scenes/Act1_Camp_MergeTest.unity`를 엽니다.
2. Play를 누르면 최신 `Gunner.prefab`이 활성 플레이어로 시작합니다.
3. 상점 NPC를 눌러 상점을 엽니다. 상점은 54개 거너 무기 중 6개를 무작위로 보여 줍니다.
4. 무기를 구매하고 장착합니다. 장착 슬롯에서는 가로로 긴 거너 아이콘이 눌려 보이지 않도록 `+90도`로 세워지고 원본 가로세로 비율을 유지합니다. 세로형 무기 장착 칸에서는 회전 전에 아이콘 영역의 가로세로를 바꿔 칸의 긴 방향을 채웁니다. 다시 인벤토리 칸으로 옮기면 원래 보관 방향으로 돌아오며, 인벤토리 아이콘만 칸 크기의 90%로 표시해 테두리 여백을 유지합니다.
5. 공격하여 총구, 비행, 명중 연출을 차례로 확인합니다.

이 씬의 `GunnerTestProjectileService`는 기존 `Manager.prefab`의 공용 투사체 풀만 활성화한 테스트용 인스턴스입니다.
다른 효과·적·데미지 텍스트 Manager는 씬의 기존 오브젝트를 사용하므로 이 인스턴스에서는 꺼져 있습니다.

## 6. 문제가 보일 때 확인할 곳

- 공격해도 아무것도 나오지 않음: 장착 무기가 있는지, `GunnerTestProjectileService/ProjectilePoolManagaer`가 켜져 있는지 확인합니다.
- 총구 연출이 옆으로 나감: 무기 루트 아래 `Muzzle`의 파란 축 `+Z`를 확인합니다.
- 라이플·유탄에서 예전 탄환과 새 탄환이 겹침: `GunnerWeaponVfxBinding`의 비행 프리팹과 기존 투사체 Renderer 숨김 처리를 확인합니다.
- 산탄 데미지가 두 번 들어가거나 중앙 탄환이 보임: `T_PlayerCombat`의 Shotgun 분기에서 `SectorAttack` 뒤에 `FireProjectile`을 호출하고 있지 않은지, 산탄 WeaponVisual의 `Projectile Visual Prefab`이 비어 있는지 확인합니다.
- 산탄이 중앙 한 점으로만 보임: 산탄총 18종의 총구 프리팹에서 두 팬 레이어의 Cone 반각이 45도인지 확인합니다. 일반·얼음·전기는 최장 파티클의 속도 `74.074`, 수명 `0.135초`로 10m를 표시합니다. 화염 3종은 최장 속도 `28.571`, 수명 `0.35초`로 10m를 표시하며 Burst 수는 0이고 연속 방출이어야 합니다.
- 유탄이 데미지를 주지 않고 바닥에 남음: `ProjectilePoolManagaer`의 `Effect Spawner`가 활성 Scene 루트의 `EffectManager`를 가리키는지 확인합니다. 선택적인 폭발 연출에서 오류가 나더라도 데미지 처리와 풀 반환은 계속되어야 합니다.
- 거너 무기 아이콘이 장착 슬롯에서 작거나 눌려 보임: `ItemUI.ResetRotationForEquipSlot`이 거너 무기만 `+90도`로 돌리고 `Image.preserveAspect`를 켜는지 확인합니다. 세로 2칸짜리 무기 장착 슬롯이 `180×360`이라면 회전 전 아이콘 영역은 반대로 `360×180`이어야 합니다. 인벤토리로 돌아왔을 때는 `preserveAspect`가 꺼지고 아이콘 영역이 칸 크기의 90%로 복구되는지도 확인합니다.
- 명중 연출이 적을 통째로 가림: 모든 거너 명중 VFX는 `GunnerVfxPlayback`에서 원본의 65% 크기로 재생됩니다.
- 다음 발사에 이전 꼬리가 남음: `GunnerVfxPlayback.StopAndClear`를 거치지 않고 투사체를 임의로 껐는지 확인합니다.
- 상점에 다른 직업 무기가 보임: `ShopStockInitializer`의 `Item Database`가 `Shop gunner.asset`인지 확인합니다.

이번 연결을 위해 팀원 코드에 추가한 부분은 모두 `SW 추가:` 주석으로 표시되어 있습니다.
